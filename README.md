# Fractal Trees Via Space Colonization Algorithm 3D

Fractal Trees Via Space Colonization Algorithm 3D is a generator and visualizer of 3D fractal trees.  
Start date: 2020-11-03  

## Demo

![Sample 1 screenshot 1](Picture1.png)

![Sample 1 screenshot 2](Picture2.png)

## Dependencies

- [Processing 4.0 beta 1](https://processing.org/download)
  - PeasyCam library

## Installation

- Open Processing (IDE).
- Open any of the `*.pde` files with Processing (IDE).

## Usage

1. Launch the program using Processing (IDE).
1. Click and drag the display to rotate the camera. Scroll to zoom.
